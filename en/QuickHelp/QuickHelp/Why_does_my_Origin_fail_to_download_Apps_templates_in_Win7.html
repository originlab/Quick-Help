5.99 FAQ-1241 Why can't I download Apps or templates in Origin on Windows 7?

Win7-Cannot-Download-App-Template

Last Update: 9/13/2026

If you are running Origin on Windows 7, you can no longer download Apps from App Center or templates from Template Center. Since Windows 7 is an outdated operating system that Microsoft no longer maintains, and due to security concerns, OriginLab website no longer supports Windows 7.

To install desired Apps or templates:

  • Download the installer from FileExchange webpage, drag and drop it into Origin workspace to install.


Note: the following features and tools are also unavailable on Windows 7:

  • System Notice (e.g., notifications about new release and features)
  • Check for update
    You can still upgrade to a newer Service Release by manually downloading the patch from our website.
  • Online License Activation
    You can still complete the activation by manually copying the activation URL and openning it in a web browser.
